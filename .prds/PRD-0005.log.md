## T-002 -- 2026-11-18

Prototyped in Python over the 913 texts, then ported to `catalog/ffd.toml` (Rust's regex has no
lookaround, so the rules use none).

- **Substance:** alcohol 414, generic drug wording 196, marijuana 9, cocaine 4, opiates 2,
  amphetamines 1, nothing named 287.
- **Role:** supervisor 549, licensed operator 158, none named 82, employee 53, contractor 51, FFD
  staff 12, security 8.
- **Kind:** positive test 638, substance found 92, other violation 78, program failure 67,
  subversion 15, refusal 13, none named 10.
- **Test:** random 420, none named 291, for cause 134, follow-up 47, pre-access 21.
- **What moved the counts.** Bare `drugs?` took alcohol positives ("random test for drugs and
  alcohol"), so generic drug wording needs its context ("illegal drug", "positive for a drug").
  "Prohibited substance" is often alcohol. `THC` needs a context too ("for THC", "(THC)"), or an
  all-caps page's "THC LICENSEE" counts. "Positive" needs a test beside it, or a tritium sample
  counts. Role order puts licensed operators and supervisors before FFD staff, so a medical review
  officer named in a supervisor's positive doesn't take the event.
