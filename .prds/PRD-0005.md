# Summary
A fitness-for-duty view over the Event Notifications: about 905 events since 1999 where a test,
a refusal, a substance found in a protected area or a program failure had to be reported, tagged
by substance, role and kind. Beside it, a national overlay of drug-related events per 100
operating unit-years against the share of the fleet in states where adult-use cannabis is legal.

# Problem
The NRC publishes FFD numbers only as annual aggregate summaries (PDFs for about 1990–2016, with no
state breakdown), and nobody has broken the reportable events down by state against legalization
dates (DESIGN.md, Prior art). The events are in PRD-0003's tables, but they need identifying,
tagging and an honest frame: only 6 of them name marijuana, and the rule decides who appears in
them at all.

# Goals
1. Every FFD event identified, checkably, with substance, role, kind and test tags.
2. Counts by year, state, substance, role and kind, with the 2008 break visible.
3. The national overlay and a state table with exposure, as Decision 38 frames them.
4. The caveats on the page: what 26.719(b) reports, and what the data can't say.

# Technical Approach
- **Identification.** `downpower_ingest::ffd` takes an event when a 10 CFR section starts with
  26.73, 26.719 or 26.417(b)(1), or when `catalog/ffd.toml` lists it. The same file lists
  reviewed exclusions. `cargo xtask ffd` writes `catalog/ffd.tsv` (number, date, state, docket,
  code, tags) from the raw store, and its diff is reviewed like the reasons snapshot's.
- **Tags.** Ordered phrase rules in `catalog/ffd.toml`, the first match winning per dimension, as
  `catalog/tags.toml` works. Each dimension has an explicit "none named" value, so a missing tag
  is visible rather than silently dropped.
- **Exposure.** Operating unit-years come from the ledger: a unit's in-service days (Decision 16)
  in each state and year, divided by 365.25. A reactor event before its unit's commercial
  operation is a construction-site event.
- **The overlay.** Two SVG charts sharing the x axis (years): drug-related FFD events per 100
  operating unit-years, with all FFD events as context, and the share of operating unit-years in
  states with adult use, and with medical use, in effect. The 2008 rule change is a marked
  vertical rule on both. The current, partial year is flagged, not dropped.
- **Where it lives.** The series are computed in the rebuild beside the monthly series and served
  from one endpoint. The page is `/ffd`, linking into `/events` through a new `ffd` filter.

# Assumptions
- PRD-0003 parses every 10 CFR section an event carries, so identification never reads the title.
- In-service unit-days are the right exposure for operating reactors. Construction sites have
  workforces of a different size and kind, so they get counts and no rate.
- Wikipedia's legalization dates are accurate enough once checked against NCSL and the statutes.
  The CSV records the source per row so a correction is one edit.

# Constraints
- One axis per chart: a dual-axis overlay is out (dataviz skill).
- No statistics library and no causal estimator in this PRD (Decision 4 reserves the staggered
  difference-in-differences for a later one).
- Stable toolchain 1.99, no chart or component library.

# Non-Goals (MVP)
- A causal estimate of legalization's effect (Decision 4, "Still open").
- The NRC's annual 26.717 summaries as a second series.
- FFD events outside reactors beyond counting them (19 at fuel cycle facilities, 6 elsewhere).
- Mapping each event's state to the worker's residence; the plant's state is the only one known.
